# Текущие задания

Сейчас активных заданий нет.

- `active.json` — текущий план карты для локального runner.
- `builder/active.json` — текущая пакетная сборка листов и предметов.
- `builder/sources/` — исходники именно текущего задания.

Создавайте эти файлы для конкретной работы. Примеры и прежние тесты не должны
оставаться активным заданием. После завершения переносите полезный пример в
`examples/` либо удаляйте его; история Git сохраняет предыдущие версии.

Базовый пример листов: [basic.json](../examples/builder/basic.json).
