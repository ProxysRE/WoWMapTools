# SPECIFICATION_0.2 — локальный упаковщик графики

Согласованный следующий шаг: один раз подготовить ресурсы клиента и разместить их на Google Drive, чтобы ассистент мог выбирать файлы без ручного экспорта каждого объекта.

## Реализовано

- Read-only binding StormLib 9.40 через ctypes, Windows Unicode x64 и Linux.
- Фиксированный порядок стандартных корневых MPQ, выбор эффективной версии по пути.
- Сохранение графических форматов и DBC, исключение аудио/видео/EXE.
- Самостоятельные ZIP около 128 MiB, группировка по виртуальным путям.
- Каталог JSONL/GZIP с SHA-256 ресурса и ссылкой на конкретный пакет.
- SHA-256 ZIP для проверки целостности, checkpoint завершённых групп, продолжение.
- Диагностика ненайденных архивов, неизвестных имён и неподдерживаемых delta-патчей.
- Листы образцов местности, используя BLP-декодер Pillow.
- Готовая Windows-сборка с DLL и лицензией зависимости через GitHub Actions.

## Границы версии

Это **подготовка хранилища**, а не автоматическая загрузка в Google Drive, не облачный Drive-клиент и не полноценный ассет-сервер. Доступ ассистента к загруженным пакетам проверяется после первой загрузки. Модели хранятся в исходном формате и ещё не преобразуются в вид сверху.

Читаются только стандартные корневые архивы; локализованные и нестандартные патчи пока исключены. Зависимости могут находиться в разных пакетах. При неполном listfile выбранный набор не считается полной копией всех ресурсов клиента.

Подробный порядок запуска: [PACK_FOR_DRIVE.md](PACK_FOR_DRIVE.md).

## Проверки

- Настоящий MPQ со сжатием zlib создан StormLib из искусственных данных; чтение, перечисление и замена модельного файла патчем проверены.
- Выбор ресурсов, исключение аудио/EXE, маркеры удаления, SHA-256 и восстановление повреждённого пакета.
- Продолжение после прерывания, отказ при изменившемся источнике, запрет вывода внутрь Data.
- Windows-совместимость нативного слоя проверяется workflow `Windows packer`.
- Полный клиент пользователя в окружении разработки отсутствует: окончательная проверка состава/объёма выполняется пользователем локально.
