# WoWMapTools

Карты и контент для **Foundry 13.351 / dnd5e 5.3.3** из ресурсов **WoW WotLK 3.3.5a**.
Ассистент составляет JSON-план, выбирает ресурсы и проверяет результат. Программа
выполняет задание; встроенного языкового ИИ и платных API нет. Seed меняет вариации
внутри плана, но не придумывает новую архитектуру.

Текущая интеграция находится в ветке **foundry-builder**. Ветка main содержит более
ранний вариант генератора. Обозначения DEV0.x описывают этапы разработки,
а не отдельные программы.

## Что работает

- MPQ читаются без изменения клиента; оригиналы сохраняются в ZIP с каталогом и SHA-256.
- Рендерятся покрытия, полы, стены, проёмы, статичные M2, мебель, детали и ограниченная расстановка окружения.
- В изображения **не встраивается сетка**. Масштаб хранится в данных.
- Экспортируются нативные сцены: стены, двери, окна, свет, зоны и переходы между этажами в отдельных сценах.
- Настоящий Builder создаёт листы, предметы и способности; население связывает NPC с токенами.
- Иконки выбираются явно; облик существа определяется через DBC. Токен сверху и портрет анфас — отдельные прозрачные изображения.
- Есть Python-проверки, проверка импортёра с имитацией API, аудит и упаковка Builder, нативные проверки MPQ на Windows и Linux.

Примеры: [таверна «Старый дуб»](OLD_OAK.md), [три NPC](FOREST_NPCS.md),
[деревня «Ольховый Брод»](ALDERFORD.md), планы в [examples](examples).
Пользователь подтвердил в Foundry стены, двери,
переходы и отображение ранних токенов. Это не означает игровую проверку
каждого нового набора способностей, материала или импорта населения.

## Границы

Есть одежда, плащи и крепления экипировки для игровых рас обоих полов и дополнительных
NPC-тел (см. CHARACTERS). Нет сборки WMO, анимационных поз, частиц и полного набора
шейдеров WoW. [Ограничения M2](MODEL_PREVIEWS.md).
Новая сцена может потребовать доработки; автоматическая тактическая проходимость
и баланс не гарантируются.

Ресурсы клиента не включаются в git. Обычный GitHub runner не получает доступ к
диску пользователя или приватному Drive из чата. Листы без WoW-изображений
собираются в Actions самостоятельно; рендеру нужны ресурсы в среде выполнения.
