# Формат сцены: базовые поля

Основные поля `wowmap.scene/1` сохраняют совместимость. Имя файла осталось прежним
для существующих ссылок; это не список возможностей текущей программы.
Дополнения: [объекты](SPECIFICATION_0.3.md), [местность и здания](SPECIFICATION_0.4.md),
[механики Foundry](FOUNDRY_EXPORT.md).

Формат `wowmap.scene/1`:

| Поле | Значение |
|---|---|
| `format` | `wowmap.scene/1` |
| `name` | Название сцены |
| `seed` | Целое число |
| `size_cells` | Ширина и высота в клетках |
| `pixels_per_cell` | Масштаб рендера |
| `distance_per_cell`, `units` | Игровой масштаб, по умолчанию 5 ft |
| `base` | Сплошное покрытие |
| `layers` | Наложения в порядке от нижнего к верхнему |
| `surface_variation` | Слабая вариация яркости 0…0.3, не источник света |

Координаты: начало в левом верхнем углу, X вправо, Y вниз. Все геометрические параметры — в клетках, перевод в пиксели только в рендере/экспорте.

Слой: уникальный `id`, `asset` (исходный полный путь либо `png:<sha256>`), `tile_cells` (ширина повтора текстуры в клетках), `opacity` 0…1.

Формы:

- `ellipse`: `bounds: [x0,y0,x1,y1]`.
- `polygon`: `points: [[x,y], ...]`.
- `path`: `points` и `width`; ломаная с круглыми стыками.
- Для всех: `feather` — радиус размытия маски в клетках; `roughness` — сила нерегулярности перехода.

PNG-каталог содержит категорию `terrain`, `model_texture` или `worldmap`. Категория выводится из пути, а не из анализа картинки. `_s` отмечается как вспомогательная текстура без предположений о её точной роли. Текстуры моделей не являются готовыми объектами с видом сверху.

Ограничение рендера: 20 млн пикселей. Импорт ZIP: максимум 512 MiB PNG в распакованном виде. Опасные пути отклоняются до записи ресурсов. Каталог объединяется при повторном импорте.
