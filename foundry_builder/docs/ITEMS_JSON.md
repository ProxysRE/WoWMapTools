# Обычные предметы и добыча → JSON

Правила предметов без активной магической механики. Применяй вместе с
`COMMON_JSON.md`. Для носимой экипировки используй `EQUIPMENT_JSON.md`, для
расходников — `CONSUMABLES_JSON.md`.

## Готовая инструкция для ИИ

1. Используй секцию `templates.item` из `templates.json`.
2. Корневой `type` должен быть `"loot"`.
3. Не добавляй `mechanics`, Active Effects или `system.activities`.
4. Заполни полное описание, количество, вес, цену, редкость и свойства, если
   они указаны в исходнике.
5. `system.type.value` принимает `treasure`, `gear`, `junk` или `material`.
6. Если предмет обладает активной магической механикой, это не `loot`: выбери
   `equipment` либо `consumable` и открой соответствующее руководство.

Обычный предмет не должен получать кнопку только ради отображения описания:
его полное правило хранится в `system.description.value`.
