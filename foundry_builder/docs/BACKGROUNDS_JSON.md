# Предыстории → JSON

Режим приложения: `background`. Отдельная команда: `background_builder.py`.
В наборе schema 4 используются `backgrounds` или `background_files`.

Предыстория — Item типа `background`, а не особенность типа `feat`.
Она содержит описание, источник, `identifier`, `advancement`, начальное
снаряжение и собственные эффекты. Нативные экспорты сохраняют неизвестные поля.

```json
{
  "type": "background",
  "name": "Пример предыстории",
  "identifier": "example-background",
  "rules": "2014",
  "description": "<p>Полные правила предыстории.</p>",
  "advancement": [
    {"type": "trait", "level": 0, "grants": ["skills:prc"]}
  ],
  "starting_equipment": []
}
```

Поддержаны Trait, AbilityScoreImprovement, ItemGrant и ItemChoice на уровне 0.
Кости хитов, размер, классовые шкалы и выбор подкласса здесь запрещены.
Ссылки вида `feature:...`, `feat:...`, `spell:...` разрешает сборщик набора.
Для одиночного документа нужны уже проверенные UUID.

`starting_equipment` — массив нативных записей dnd5e `startingEquipment`.
Сборщик сохраняет такие записи, но не превращает текстовый список вещей в
полностью настроенные выборы экипировки. Если нативные ссылки и схема не
проверены, сохраните варианты снаряжения и деньги в полном описании и отметьте
их ручную выдачу. Пустой массив не означает автоматизированную выдачу вещей.

Владения, которые игрок получает позже по сюжету, нельзя автоматически выдать
при создании. Условия сохраняйте в тексте, а ручную часть — в контракте
связанной особенности `automation.manual`.

Нативный источник структуры: dnd5e release-5.3.3,
`module/data/item/background.mjs`. Перед выпуском проверьте выдачу черт,
владений и выборов на новом листе персонажа.
