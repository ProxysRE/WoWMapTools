# Ольховый Брод — деревня в трёх сценах

Авторское людское поселение для кампании WoW. Это не копия канонического населённого
пункта. Карты используют оригинальные ресурсы WotLK 3.3.5a и геометрию WoWMapTools.
Цель — Foundry 13.351 / dnd5e 5.3.3.

## Устройство

Три фрагмента деревни следуют с севера на юг. Каждая сцена — **48×36 клеток**,
**80 px на 5 ft**, **3840×2880**. Север наверху. На картинке нет сетки.

1. **Северные ворота:** дорога, частокол с открываемыми воротами, два поста,
   караульный дом, конюшня и площадка осмотра повозок. Здесь видна северная
   часть ограды. Остальной периметр существует за пределами этих карт.
2. **Торговая площадь:** хлебный, рыбный, сырный и посудный ряды, пекарня,
   кузница, склад артели и дом ткачихи. Боковая дорога служит для разгрузки.
   Частокола по краям нет: это внутренний участок поселения.
3. **Площадь ратуши:** колодец, доска объявлений, постоялый дом «Три ольхи»,
   часовня, жилые дворы и ратуша с залом собраний, кабинетом и архивом.
   Частокола здесь также нет. Главная дорога заканчивается у ступеней ратуши.

Здания показаны без крыш, с доступными интерьерами. Двери, окна, свет и переходы —
нативные документы Foundry. Дневной глобальный свет включён, темнота 0.12.
Закрытые двери можно открывать; у главных входов дневной вариант состояния открыт.

Переходы: южный край ворот ↔ север рынка; юг рынка ↔ север площади ратуши.
Игрок подтверждает переход. Зоны прибытия отделены от зон выхода, чтобы после
прибытия токен не попадал сразу в обратную зону.

## Население и зацепка

В комплекте **9 листов NPC и 16 размещённых токенов**. Пять рядовых стражников
используют один базовый лист с независимым состоянием экземпляров. Именные NPC
связаны со своими листами; покупатели также имеют независимое состояние.

| NPC | Место и роль |
|---|---|
| Капитан Роланд Вейл | Караульный дом; ищет пропавшую повозку без лишней паники |
| Йорен — возчик | У ворот; видел следы тяжёлого обоза |
| Марта — пекарь | Хлебный ряд; запомнила ранних посетителей |
| Элина — торговка | Рыбный ряд; знает о вскрытом складском замке |
| Борен — кузнец | Мастерская; узнал глину старого карьера на чужой подкове |
| Староста Адриан Холт | Ратуша; скрывает недостачу общих запасов |
| Вера — хозяйка постоялого дома | Запомнила гостя, который не снимал перчатки |
| Писарь Мартен | Архив; нашёл несовпадение накладных и записей на воротах |

Простая связка для игры: исчезновение муки оказывается связано с подменёнными
накладными. Мастер решает, кто виноват; биографии дают свидетелей и улики,
но не навязывают развязку. Запасы на карте — декорации, не автоматически
создаваемые инвентари или торговая экономика.

У стражников есть атака копьём, у капитана — длинным мечом. Гражданские созданы
для разговоров и сцен; боевые атаки им не добавлены. CR авторский и ориентировочный.
Изображения берутся из готовых людских моделей: экипировка листа не навешивается
на тело автоматически. Токены и отдельные портреты сохраняют статичную базовую
позу, без анимации. Это прозрачные WebP, не интерактивные M2.

## Импорт готового комплекта

1. Распакуйте комплект в отдельный каталог.
2. Скопируйте **только папку `wowmap`** в пользовательскую **Data сервера Foundry**,
   объединяя с существующей папкой. JSON, отчёты и превью остаются вне Data.
3. Создайте макрос **Script** из `import-foundry.js`, запустите от мастера.
4. Используйте путь `wowmap/alderford-village/bundle.json`.
5. Импортируются все три сцены и девять актёров. Отдельно импортировать листы NPC
   не нужно. Старые документы не перезаписываются; повторный импорт остановится
   на конфликте ID.

В архиве есть чистые фоны и обзорные планы для мастера с подписями. Подписи
не встроены в игровые фоны. Для перехода игрокам нужны соответствующие права
Foundry и владение токеном; подробнее — [экспорт сцен](FOUNDRY_EXPORT.md).

## Воспроизведение

```console
python tools/build_alderford.py
python tools/check_alderford.py --packages D:\WoWAssets\Village
python -m wowmap render examples/alderford-gate.json --packages D:\WoWAssets\Village --out output/alderford-gate
python -m wowmap render examples/alderford-market.json --packages D:\WoWAssets\Village --out output/alderford-market
python -m wowmap render examples/alderford-civic.json --packages D:\WoWAssets\Village --out output/alderford-civic
python -m wowmap.foundry --scene output/alderford-gate --scene output/alderford-market --scene output/alderford-civic --id alderford-village --out output/alderford-export
python tools/build_foundry_batch.py requests/builder/alderford.json --icon-assets D:\WoWAssets\Icons --dbc-assets D:\WoWAssets\DBC --model-assets D:\WoWAssets\Village --out output/alderford-npcs
python -m wowmap.population --bundle output/alderford-export/wowmap/alderford-village/bundle.json --population output/alderford-npcs/population.json
```

Нужны соответствующие ZIP из существующей выгрузки; исходный клиент не требуется.
Для повторной пакетной сборки и экспорта выберите пустые каталоги назначения.
Список использованных ресурсов и их пакетов входит в готовый отчёт комплекта.

## Проверка и границы теста

Проверка планировки использует диск диаметром 5 ft, шаг 0.2 клетки, стены,
двери как открываемые и XY-прямоугольники выбранной крупной мебели. Проверяются
центры NPC, доступ к основным местам и зонам переходов. Это дискретная проверка,
а не эмулятор Foundry; она не доказывает возможность прохода любого большого токена.
Колодец проверяется по месту подхода, а не по непроходимому центру чаши.

При подготовке найден и исправлен перекрытый лавками подход к двери архива.
Недостающие материалы мебели, повозок и наковальни найдены в других пакетах
по каталогу, а не заменены случайными текстурами. Некоторые модели деревьев
ссылаются на отсутствующие в выгрузке UI-текстуры; они не использованы.

Один общий фон 48×108 при 80 px содержал бы 33 177 600 пикселей и превысил
ограничение 20 млн. Три сцены имеют по 11 059 200 пикселей и проходят его.
Результаты рендера и QA входят в отчёты комплекта; реальная игровая проверка
этой деревни в установленном Foundry выполняется мастером отдельно.
