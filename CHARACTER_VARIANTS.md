# Варианты внешности и снаряжения

Инструмент `wowmap.character_variants` создаёт до 24 комплектных обликов по запросу и seed. Характеристики NPC и сцена создаются отдельно через Builder. Клиентские ZIP остаются приватными.

## Внешность

`bodies[].character` задаёт расу, пол и фиксированные параметры. Незафиксированные skin, face, hair_style, hair_color и facial_hair выбираются из родных DBC 3.3.5a. Это индексы доступных деталей, не произвольный цвет или редактор пропорций тела. Значение facial_hair зависит от расы: борода, украшения и другие детали.

Лицо выбирается в рамках допустимой кожи, цвет волос — в рамках причёски. Фиксированное лицо заранее ограничивает возможные кожи, фиксированный цвет — причёски. Недопустимые фиксированные сочетания дают ошибку.

Профиль `normal` исключает DK-записи CharSections и специальные NPC-палитры игровых рас. `death_knight` разрешает общие/DK-варианты явно; `npc` разрешает дополнительные NPC-палитры, но исключает DK. Проверка действует и при случайном выборе, и при явных индексах. Профиль меняет внешний вид, а не класс листа.

## Комплекты и случайные вещи

`outfits[].equipment` фиксирует Item ID по слотам. `equipment_pools` выбирает по одному элементу из каждого указанного списка. `null` означает оставить слот пустым. Один слот нельзя одновременно фиксировать и случайно выбирать; повторяющиеся ID запрещены, чтобы не создавать скрытые веса.

```json
{
  "id": "traveller",
  "equipment": {"legs": 10035, "boots": 43},
  "equipment_pools": {
    "chest": [285, 14152],
    "main_hand": [25, 35],
    "off_hand": [null, 143],
    "cape": [null, 1190, 1270]
  },
  "pose": "combat"
}
```

Это выбор из подготовленного набора; инструмент не перебирает вслепую все предметы клиента. Для тематической одежды задавайте соответствующий пул. Совместимость проверяется настоящей сборкой: слот, наличие текстуры/геометрии, тип тела, крепление и поза. Двуручное оружие со щитом отклоняется; при наличии допустимых альтернатив подбирается другое сочетание. Если для назначенного тела/комплекта вариантов недостаточно, вся подборка завершается ошибкой — неподходящее тело не исчезает молча.

Распределение тел и комплектов учитывает их представленность в короткой подборке, пары не повторяются до перебора полного набора. Seed воспроизводит результат при неизменных ресурсах и алгоритме. Текущий алгоритм — `balanced-conditional/2`; выбор по старому алгоритму при том же seed может отличаться.

Разные параметры могут дать одинаковое изображение, например под закрытым шлемом или мантией. `same_rendered_images` перечисляет совпавшие пары, чтобы это было видно автору.

## Отсутствующие накладки

Основные материалы тела, волос и экипировки проверяются при сборке выбранной геометрии; отсутствующая используемая текстура не заменяется заглушкой. Дополнительные вторичные накладки скальпа и растительности на лице могут отсутствовать в исходном наборе клиента (подтверждено для эльфов крови). Они пропускаются с явной записью `kind: scalp_overlay` или `facial_overlay` в `warnings` и provenance; это не подмена основной текстуры волос. Остальные отсутствующие накладки в подборщике остаются ошибкой. Облик с предупреждением нужно посмотреть на контактном листе.

## Ракурс и поза

Токен всегда сверху, yaw=-90. Portrait_yaw задаётся независимо. Поза по умолчанию combat; idle/bind и конкретные кадры разрешены явно. Отсутствующая запрошенная анимация не заменяется обычной стойкой. Это статические изображения, не живое воспроизведение.

## Запуск и результат

```console
python -m wowmap.character_variants --request requests/character-wardrobe.json --dbc-assets D:\WoWAssets\DBC --model-assets D:\WoWAssets\Models --out output/wardrobe
```

`variants.json` содержит конкретные внешности, выбранные предметы, счётчики представленности, предупреждения, причины отклонений и источники. `variants-review.jpg` показывает портреты и токены; `wowmap/content` содержит готовые WebP. Данные appearance можно перенести в batch Builder. Частичная подборка не публикуется.

Проверка на оригинальных данных:

```console
python tools/audit_customization.py --dbc-assets D:\WoWAssets\DBC --model-assets D:\WoWAssets\Models --out output/customization-audit
```

Проверены люди, орки и эльфы крови обоих полов; поддержка прочих тел описана в CHARACTERS.md и не означает повторный визуальный тест всех их комбинаций. Одежда и плащи могут пересекаться в конкретном кадре: автоматической подгонки геометрии и эффекта чар нет. Проверка в живом Foundry указывается отдельно.
