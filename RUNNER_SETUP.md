# Локальный исполнитель GitHub Actions

Настраивать после проверки ручного рендера. Для DEV0.1 это позволяет запускать готовые планы с уже импортированными PNG; прямой поиск в MPQ появится отдельно.

## Предварительно

- Windows ПК включён и подключён к сети.
- Python 3.10+ с `py` launcher.
- Отдельная постоянная папка ассетов вне рабочей папки runner, например `D:\WoWMapTools\Assets`.
- Не публикуйте клиент и ассеты в репозитории.

Локальный runner исполняет код из репозитория на ПК. Workflow разрешает только `main` и ручной запуск, не pull request. Сохраняйте запись в `main` только для доверенных участников; для постоянного использования локального исполнителя предпочтителен приватный репозиторий.

## Настройка

1. Импортируйте существующий ZIP в постоянную папку:

   ```console
   python -m wowmap import-png "D:\Exports\PNG.zip" --assets "D:\WoWMapTools\Assets"
   ```

2. Откройте репозиторий → Settings → Actions → Runners → New self-hosted runner. Выберите Windows x64 и выполните предложенные GitHub команды в отдельной папке. Токен регистрации вводится только локально; в чат его передавать не нужно.
3. При регистрации добавьте дополнительную метку `wowmap`. Стандартные метки должны включать `self-hosted`, `Windows`, `X64`.
4. В Settings → Secrets and variables → Actions → Variables создайте:

   | Переменная | Значение |
   |---|---|
   | `WOWMAP_ASSETS` | `D:\WoWMapTools\Assets` |
   | `ENABLE_LOCAL_RENDER` | `true` |

5. Запустите runner согласно инструкции GitHub. Не размещайте постоянные ассеты внутри `_work`: checkout может очистить рабочую копию.
6. Actions → Render on local Windows runner → Run workflow. Будет обработан `requests/active.json`.
7. В результате запуска скачайте артефакт `wowmap-render`. Последующие изменения `requests/active.json` в `main` запускают его автоматически.

Результаты хранятся как артефакты 7 дней. В публичном репозитории результаты workflow доступны согласно правилам доступа GitHub; для непубличных карт используйте приватный репозиторий.

Если runner выключен, задание ждёт его подключения. Выключение `ENABLE_LOCAL_RENDER` отключает запуск новых заданий.

## Пока не реализовано

- Исполнитель не читает клиент MPQ и не подбирает модели автоматически.
- Программа не является постоянно доступным сервером и не открывает порт на ПК.
- Файлы превью ассетов пока создаются командой `gallery`; отдельный протокол заданий на каталог появится в DEV0.2.
