# Формат сцены: статические объекты M2

## Реализовано

- Исходный план `wowmap.scene/1` расширен массивом `objects`.
- Текстуры местности BLP могут читаться напрямую из подготовленных ZIP, без повторного PNG-экспорта.
- M2 рендерится сверху один раз, затем используется PNG-спрайт с прозрачностью.
- Содержимое M2/SKIN/текстур и версия рендера определяют ключ кэша.
- Масштаб, поворот по часовой стрелке, непрозрачность и исходная точка привязки M2.
- Раздельные слои `ground`, `props`, `overhead` и явный порядок перекрытия.
- Декоративные мягкие тени, которые при необходимости можно отключить.
- Отдельные фон и верхний слой для [экспорта Foundry](FOUNDRY_EXPORT.md).
- Исправлено переполнение UV-индекса на границе текстуры при отрицательных координатах около нуля.
- Кнопка Windows `render_camp.bat` и CLI без графического окружения.

## Объект в JSON

```json
{
  "id": "tent-1",
  "model": "world/generic/nightelf/passive doodads/tent/nightelfsingletent01.m2",
  "position": [16, 11],
  "size_cells": 3.3,
  "scale": 1,
  "rotation": 125,
  "layer": "props",
  "order": 0,
  "opacity": 1,
  "shadow": {
    "opacity": 0.22,
    "blur_cells": 0.16,
    "offset_cells": [0.14, 0.22]
  }
}
```

- `position`: координаты привязки в клетках от верхнего левого угла карты.
- `position_anchor`: `origin` по умолчанию (исходное начало M2), либо `bounds-center`
  для центра XY-габаритов. Это не автоматический поиск ног или физического центра.
- `size_cells`: длина большей стороны геометрического XY-габарита модели до поворота; пустые поля PNG в размер не входят.
- `scale`: дополнительный множитель размера, по умолчанию 1.
- `rotation`: градусы по часовой стрелке; точка `position` остаётся неподвижной.
- `layer`: сначала `ground`, затем `props`, затем `overhead`.
- `order`: порядок внутри слоя; при равенстве сохраняется порядок объектов в JSON.
- `opacity`: 0…1, по умолчанию 1. Тень отключена, если `shadow` отсутствует либо равно `false`.

Значения масштаба в примере выбраны для настольной карты, а не автоматически переведены из игровых ярдов. Верхний слой содержит целые объекты, назначенные ему автором: автоматического отделения кроны от ствола пока нет.

## Запуск

```console
python -m wowmap render examples/ashenvale-camp-objects.json --packages "D:\WoWMapTools\Packages" --out output/camp
python -m wowmap validate examples/ashenvale-camp-objects.json --packages "D:\WoWMapTools\Packages"
```

Или `render_camp.bat`: выберите каталог с ZIP-пакетами. Нужен установленный Python и зависимости из `setup_windows.bat`. StormLib.dll для рендера готовых пакетов **не требуется**.

Каталоги ZIP читаются при открытии. CRC проверяется при чтении конкретного ресурса; все 6 ГиБ не перечитываются для проверки при каждом запуске. При необходимости полная проверка доступна через Python API `RawAssets(folder, verify_archives=True)`.

## Пример и ресурсы

`examples/ashenvale-camp-objects.json`: 3200×2400, 40×30 клеток, 80 px/клетку, 44 объекта и 19 уникальных моделей. Три палатки, незажжённое кострище, дрова, бочки, ящики, камни, брёвна, пни и деревья. Центральная тропа и место для перемещения остаются открыты.

Для примера нужны следующие стандартные пакеты из набора DEV0.2:

## Выходные файлы

| Файл | Назначение |
|---|---|
| `map.png` | Полная карта |
| `map-ground.png` | Карта без верхнего слоя деревьев |
| `objects-ground.png` | Прозрачный слой обычных объектов и их теней |
| `objects-overhead.png` | Прозрачный верхний слой |
| `preview.jpg` | Уменьшенное превью |
| `objects.json` | Размещение и фактические габариты в пикселях |
| `scene-plan.json` | Исходное задание |
| `render.json` | Размеры и параметры рендера |

При `export_format: "webp"` изображения имеют расширение `.webp`. Сетка не запекается;
`map-vtt.webp` создаётся для VTT без верхнего слоя и дверных полотен.

Тени в этих изображениях запечены; они не заменяют динамические источники света.
Экспортёр переносит верхний слой в общий tile. Для раздельного скрытия крыш и крон
нужны отдельные тайлы: [настройки Foundry](FOUNDRY_EXPORT.md).

## Границы версии

Статический базовый вид M2 с ограничениями `MODEL_PREVIEWS.md`. Нет частиц, скелетной анимации, точных игровых шейдеров, динамического света, WMO и автоматической разметки препятствий. `render.json` — параметры рендера, **не сцена Foundry**. Нативный экспорт стен,
дверей, окон и света выполняется отдельной командой: [инструкция](FOUNDRY_EXPORT.md).

## Проверки

- Поворот нецентрированной модели сохраняет исходную точку привязки.
- Положительный угол поворачивает по часовой стрелке.
- Слои и явный порядок меняют перекрытие предсказуемо.
- Повторный рендер воспроизводим и использует кэш.
- Отсутствующая зависимость обнаруживается до записи результата.
- Настоящая карта собрана из предоставленных ресурсов WoW и визуально проверена.
