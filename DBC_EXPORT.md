# DBC: отдельная выгрузка и основа для токенов существ

Режим `pack_dbc.bat` читает стандартные корневые MPQ и архивы **одного языка**,
включая стандартные патчи. Сохраняются только `DBFilesClient/*.dbc`, в исходном виде.
Модели, текстуры, иконки и звук повторно не выгружаются. Для всех языков сразу
таблицы не смешиваются: если языков несколько, укажите `--locale` явно.

## Что сделать на Windows

1. Скачайте артефакт **WoWMapTools-DEV0.6.2-Windows** успешного запуска **Windows packer**
   ветки **foundry-builder**. Конкретная ссылка на запуск передаётся вместе с инструкцией.
2. Распакуйте артефакт, затем ZIP программы внутри него, желательно в новую папку.
3. Запустите `setup_windows.bat`, затем **`pack_dbc.bat`**.
4. В окне выбора укажите **Data клиента**, а не подпапку `ruRU` или `enUS`.
5. Дождитесь завершения. Откроется `output\dbc-export\upload`.
6. Создайте отдельную папку **«WoW DBC»** на Google Drive и загрузите содержимое
   `upload`, сохраняя структуру подпапок. Передайте ссылку ассистенту.

Прежние выгрузки моделей и иконок сохраняются. Не заменяйте их каталоги новыми.
Исходные MPQ не изменяются. Точный объём программа покажет после индексации;
не надо заранее рассчитывать на определённое количество мегабайт.
BAT использует части по 32 MiB; большая отдельная таблица может превысить этот предел.

## Что в результате

- `summary.json` — статус, архивы-источники, SHA-256 пакетов и предупреждения;
- `catalog.jsonl.gz` — путь таблицы → ZIP, исходный SHA-256 и имя внутри ZIP;
- `dbc-report.json` — проверенные WDBC-заголовки, количество строк, полей,
  размер записи, размер строкового блока и наличие таблиц для внешности;
- `packages/*.zip` — исходные DBC, без преобразования и потери данных;
- `inventory.jsonl.gz` и `READ_ME.txt` — служебное описание выгрузки.

Повреждённая таблица, неправильная сигнатура или несоответствие размеров останавливают
экспорт со статусом `failed`, а не `complete`. Отсутствие одной из интересующих нас
таблиц попадает в предупреждения; остальные корректные таблицы всё равно сохраняются.
Наличие таблиц само по себе не означает, что их записи, связи и все ресурсы уже проверены.

`WDBC` не хранит надёжный номер сборки клиента. Программа не объявляет неизвестную
таблицу «точно 12340» и не пытается угадывать названия её колонок.
Нестандартные/буквенные патчи не включаются. Delta-патчи отклоняются.

## Какие связи нам нужны

| Таблицы | Назначение следующего этапа |
|---|---|
| CreatureDisplayInfo, CreatureModelData | ID облика, модель, варианты текстур |
| CreatureDisplayInfoExtra | Внешность готовых гуманоидных NPC, ссылки на экипировку |
| ChrRaces, CharSections, CharHairGeosets, CharacterFacialHairStyles | Базовое тело, кожа, лицо, волосы и отдельные части геометрии |
| Item, ItemDisplayInfo, HelmetGeosetVisData | Внешний вид экипировки и скрываемые части модели |
| ItemVisuals, ItemVisualEffects | Визуальные эффекты предметов |
| AnimationData | Названия/типы анимаций; сами движения находятся в моделях и ANIM |
| SpellIcon | Связь ID значков с файлами иконок |

Схемы сверяются с определениями **WoWDBDefs** для 3.3.5.12340, а формат WDBC —
с загрузчиком **TrinityCore** ветки 3.3.5:

- https://github.com/wowdev/WoWDBDefs/tree/master/definitions
- https://335.trinitycore.net/db/dab/dbcfileloader_8cpp_source

Это не серверная база NPC: клиентские таблицы не содержат всех имён, характеристик,
содержимого инвентарей и правил экипировки существ. Игровые листы по-прежнему создаёт
наш Builder по задаче мастера. Отдельные модели, скины, текстуры и анимации выбираются
из уже загруженных графических пакетов по найденным связям.

## Команды и диагностика

```console
python -m wowmap.pack --profile dbc --part-mib 32 --locale ruRU
python -m wowmap.pack --profile dbc --index-only
python -m wowmap.dbc extracted/CreatureDisplayInfo.dbc
```

Первая команда откроет выбор Data, результат — `output/dbc-export`.
Если файлов не найдено, передайте `output/dbc-export/scan-diagnostic.json`.
Поддерживается внешний `--listfile`, как в остальных профилях.
Для продолжения повторите прежнюю команду; при смене настроек используйте новый `--out`.

## Состояние реализации токенов

Готовы выгрузка, проверка WDBC и базовый читатель типизированных ячеек/строк.
Добавлен первый [рендер токенов по ID облика](TOKENS.md): реальные волки трёх окрасок,
назначение прототипу NPC и перенос с населением карты. Скелетные позы и сборка
гуманоидов с одеждой и оружием ещё не реализованы.
Токены планируются как изображения с прозрачностью; обычная сцена Foundry
не становится трёхмерным просмотрщиком M2.
