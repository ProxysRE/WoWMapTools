# Технические примеры Builder

Эти файлы демонстрируют возможности программы и не относятся к населению
текущей кампании. Они не запускаются как текущее задание при обычном push.

- `basic.json` — два NPC, предмет и заклинание без ресурсов WoW.
- `icons-demo.json` — назначение значков; нужны приватные иконки.
- `tokens-demo.json` — существа по ID облика; нужны DBC и модели.
- `all-races.json`, `human-outfits.json`, `capes.json` — тела, одежда и плащи.
- `pose-demo.json` — позы; `material-fixes.json` — проверка материалов.

Пути `source` разрешаются от корня репозитория.
`basic.json`, `icons-demo.json` и их исходники используются регрессионными
проверками: это необходимые контрольные данные, а не результаты тестов.
