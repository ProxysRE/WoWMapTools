# «Старый дуб» — проработанный постоялый двор, DEV0.6

Два согласованных этажа на окраине Ясеневого леса. Это авторское здание в стилистике WoW, не копия канонической таверны. Все модели и покрытия взяты из WotLK 3.3.5a; небольшая архитектурная отделка задаётся геометрией программы. Встроенного ИИ и нейросетевой дорисовки нет.

## Устройство здания

Вход с дороги ведёт прямо в общий зал. Центральный проход оставлен свободным: к столику регистрации и лестнице можно пройти, не протискиваясь между стульями у стойки. В зале четыре стола на четверых, общий стол с лавками, небольшой пристенный стол и четыре места у стойки. Северо-западная гостиная отделяется дверями для спокойных разговоров.

За стойкой есть рабочий проход. Из него доступны кухня, кладовая и служебная дверь лестничного холла. Кухня имеет отдельный разгрузочный вход со двора, каменный пол, горячую зону у дымохода, подготовительный стол и место для мытья посуды. Запасы хранятся по краям кладовой, проход к её двери освобождён.

На втором этаже — две двухместные и две одноместные комнаты, общая спальня на четверых и комната хозяев. Всего **10 гостевых спальных мест**, отдельно от кровати хозяев. В небольшом номере сознательно оставлена одна кровать: две мешали нормальному проходу. У гостей есть столы, умывальные места и места для вещей. На лестничной площадке — бельевая и скамья. Положение наружных стен, дымоходов и лестницы согласовано между этажами; внутренние перегородки верхнего этажа опираются на деревянное перекрытие.

Во дворе — колодец, дрова, поставленные у разгрузочного входа ящики и бочки, небольшой огород и отдельная двухместная уборная. К парадному крыльцу и служебному входу ведут разные подходы.

## Что изменено в программе

- `position_anchor: "bounds-center"`: точное размещение предмета по центру габаритов вместо смещённого начала координат M2. Старые планы сохраняют прежнее поведение.
- `architecture`: тёмная кромка среза стены и мягкое затемнение у её основания. Эти декоративные тени не подменяют динамический свет Foundry и строятся без дверных полотен.
- `details`: небольшие линии, прямоугольники, эллипсы и полигоны для ступеней, стоек, кладки и отделки. Это геометрия, а не сетка.
- Сценарий `tools/check_old_oak.py` проверяет доступ к основным помещениям диском диаметром **5 футов**. Он учитывает стены, открываемые двери и реальные XY-габариты выбранной крупной мебели. Это дискретная проверка планировки, не эмулятор физики Foundry и не гарантия прохода через каждый промежуток между предметами.

В готовом варианте — **282 размещения моделей** на двух сценах, включая повторяющееся окружение двора. Стены, двери, свет и лестница экспортируются штатным экспортёром DEV0.5. Сетка на картинках отсутствует. Масштаб — **96 px / 5 ft**, изображение каждого этажа — **3456 × 2880 px**.

## Свет и импорт

Это дневной вариант: включён глобальный свет, темнота 0.18. Местные источники дают дополнительный тёплый свет; карта не становится полностью чёрной вне их радиусов. Ночной вариант можно создать отдельным планом с отключённым global_light, но здесь он не включён.

Комплект рассчитан на Foundry 13.351 и используется с dnd5e 5.3.3. Правил персонажей и зависимых от системы макросов в нём нет. Пользователь уже проверил стены, двери и переходы на предыдущем комплекте DEV0.5; новый художественный вариант требует осмотра в его игре.

1. Добавьте папку **old-oak-dev06** из архива в уже существующую **Data/wowmap**. Старый комплект таверны остаётся отдельным каталогом.
2. Создайте Script-макрос из нового **import-foundry.js**, запустите от мастера.
3. Оставьте путь **wowmap/old-oak-dev06/bundle.json**. Импортируются две новые сцены, прежние не заменяются.
4. Внутри архива есть обзорные изображения, пронумерованные планы для мастера, исходные планы и результат проверки маршрутов.

## Повторное создание

Обновите программу до DEV0.6. Повторно экспортировать клиент WoW не требуется. Для колодца дополнительно использован пакет `world-azeroth-duskwood-fa40c120-001.zip` из ранее загруженного набора; зависимости сцены можно проверить командой каталога.

```console
python tools/build_old_oak.py
python tools/check_old_oak.py --packages D:\WoWAssets
python -m wowmap render examples/old-oak-ground.json --packages D:\WoWAssets --out output/old-oak-ground
python -m wowmap render examples/old-oak-upper.json --packages D:\WoWAssets --out output/old-oak-upper
python -m wowmap.foundry --scene output/old-oak-ground --scene output/old-oak-upper --id old-oak-dev06 --out output/foundry-old-oak
```

Скрипт построения создаёт обычные JSON-планы — дальше их можно править независимо. Он не меняет ядро под конкретную карту и не содержит изображений из игры. `render_scene.bat` может открыть любой из созданных планов.

## Честные ограничения этого варианта

- Разные этажи — отдельные сцены, связанные зонами перехода. Это не высотная модель одного помещения.
- Полотна дверей не запечены в игровом фоне; двери открываются штатными значками Foundry.
- Кроны двора — общий верхний слой; частицы огня, дым и анимированная вода не рендерятся.
- Мелкая посуда в реальном масштабе остаётся мелкой; для просмотра деталей нужен зум.
- Крупная мебель учтена в проверке планировки, но не вся мебель автоматически превращена в препятствия Foundry. Отдельные ограничения заданы для стойки, перил и колодца; на столы можно ставить токены по решению мастера.
